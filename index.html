How to use

1. Keep the regular class dates as per your timetable.
2. Enter the actual Total Recorded and Present count shown in your attendance portal. If a faculty did not mark attendance, do not add that missing attendance to the recorded total.
3. Add any extra holidays using Add Holiday. A holiday is removed from attendance calculation, but it does not change the slot rotation.
4. If attendance is marked during an exam day, enter those counts in Exam Attendance and press Add Counts.
5. The result shows your current percentage, final percentage if you attend all remaining classes, attendance count you can still miss, and maximum future sessions you can miss.

Important:

  • Morning = 2 attendance count
  • Afternoon = 1 attendance count.
  • Sundays have no classes.
  • The timetable rotation continues continuously
